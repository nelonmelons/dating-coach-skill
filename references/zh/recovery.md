# 止损、收尾与体面地失败

适用于：兴趣在降温、对方已经拒绝、约会很平淡，或者用户纠结要不要继续。

## 目录
1. 三档止损
2. 救回一段冷掉的聊天
3. 体面收尾话术
4. 她吐槽、情绪不好的时候
5. 帮用户走出沉没成本

---

## 1. 三档止损

看能观察到的事实，不看感觉，也不看自己编的"好感度百分比"。

| 档位 | 触发条件 | 用户该做什么 |
|---|---|---|
| **1. 冷却** | 几天里回复越来越短；模糊邀约没接；被鸽一次且没提改期 | 一周左右不主动找她。过好自己的日子，朋友圈发真实的生活。之后发一条轻松、新鲜的重启消息（见 `texting.md` §6）。 |
| **2. 体面收尾** | 重启消息没回或者回得很敷衍；两次邀约都被拒且没给替代时间；连着两次说"最近好忙" | 发一条温和的收尾，把门留着："没事哈，跟你聊天挺开心的，祝一切顺利。"然后停。 |
| **3. 彻底停止** | 明确拒绝；"我对你没感觉"；被删或拉黑；她要求别再联系 | 不再有任何联系。禁止：换号加回、托朋友传话、跑去她出现的地方堵人、去点赞她以前的朋友圈刷存在感、"就最后发一条"。 |

不管在哪一档，只要她主动回来找你，就正常、热情地接住，不要报复，不要质问，然后往见面推进。

## 2. 救回一段冷掉的聊天

1. **先找出是哪一步出了问题**（见 SKILL.md 的阶段模型）。从没回过 → 头像、资料或第一印象。聊着聊着淡了 → 聊天本身。约会后冷了 → 约会本身或推进节奏。
2. **两件事：** 让她看到你真实的变化，同时让那个尴尬的时刻慢慢淡掉。大约一周不联系，这期间朋友圈展示你真实的生活。
3. **简单地重启：** 一个"嗨"、一个之前的梗、或者一件新鲜轻松的事。不要"在干嘛"，不要"美女"，不要"不好意思之前是不是有点奇怪"。
4. **一次只发一条。** 她接住了，就先把聊天的感觉找回来，再谈邀约。没接住，就进第 2 档。

## 3. 体面收尾话术

- **被拒了，但你们是同事、同学或者一个朋友圈子的：** 大方地回应一次，然后完全正常相处。"完全理解，我这边不会尴尬的。"不要翻旧账，不要躲着她，不要拉朋友帮你说话。
- **表白太早，对方反应很冷淡：** "嗯理解，我就是习惯有啥说啥，你别有压力哈。"然后回到轻松好玩的状态，靠行动慢慢重建，别再表白第二遍。
- **"你人很好，但是……"：** 相信她。"谢谢你跟我说实话。"不要辩解，不要争取。
- **"我现在不想谈恋爱"：** 按字面意思理解。你想认真谈，就体面退出；你真心愿意做朋友，也可以，但别把做朋友当成等待的策略。
- **约会很平淡：** 发一条简短、礼貌的消息（"今天谢谢啦，很高兴认识你"）；如果她已经明显没兴趣，不发也行。别为了一次平淡的约会再安排一个大计划去追。
- **她突然带了闺蜜来：** 热情一点，把闺蜜也照顾到，这是她在让朋友帮忙把关。别甩脸色，也别去撩她闺蜜让她吃醋。
- **聚会上碰到前任（或她的前任）：** 简短礼貌地打个招呼，然后回到自己的朋友那边。不表演，不搞事。
- **约会时你自己出了糗：** 轻松地认一次（"刚那个梗死得很惨"），别越想越纠结。

## 4. 她吐槽、情绪不好的时候

别急着给建议、开玩笑或者说"我比你还惨"。先接住她的情绪、表示理解，再问她需要什么：
> 啊这也太累了吧。你是想要我给建议，还是想要我陪你一起骂？

然后跟着她的需要走。这种时候认真回应她，比任何撩人的话都更能拉近距离。

## 5. 帮用户走出沉没成本

- "可我们都聊了好几周了" → 聊了多久不代表她有兴趣，最近这几次聊天才说明问题。
- "再试最后一次" → 如果已经到了第 2、3 档，再试一次会消耗你的自尊，也会让她以后更不可能回头。
- "她是不是在测试我" → 拒绝不是测试，"不"就是"不"。
- **接下来这一周：** 见朋友，做一件你擅长的事，认识新的人。选择多了，需求感自然就降了；被拒绝只是她没选你，不是对你这个人的否定。
