## 1. 形象和资料

- **干净利落，不浮夸。** 合身和面料比 logo 重要；打理好细节（鼻毛、指甲、发型）；一款好闻的香水。小动作越少，越显得有气场。
- **照片：** 6–10 张真实的、在做真实事情的照片——一张清楚的正脸、一张全身、一张爱好、和朋友的（要一眼认得出哪个是你）、旅行或者户外活动。第一张别放合照，别全是墨镜照，别用对镜自拍当头图。
- **朋友圈就是你的简历。** 约会前、或者重新联系前，对方一定会翻。朋友圈是你的展示面：展示真实生活，删掉丧的、抱怨的、炫耀的。别设"三天可见"让人什么都看不到，也别全是转发鸡汤和工作广告。
- **个人简介：** 写对方能接话的具体钩子（"会审判你点的奶茶甜度"），比一串形容词好。
- **绝对不要：** 网图、借来的车、摆拍营造人设。见面时落差带来的损失，远大于照片当初赚到的。

## 2. 线下搭讪

- **挑有时间的人。** 在逛街、拍照、等人的人是开放的；穿着工作服赶路的人不是。忙的人拒绝你，跟你本人无关。
- **给时间框：** "能占用你半分钟吗？" 打消对方"这人会不会一直不走"的担心。别说"我不是推销的"——推销的人才这么说。
- **给一个真实理由：** "刚路过看到你……" / "你看起来很熟这边，附近哪有好喝的咖啡？" / "你看起来对这个会有很强的意见"。描述，别猛夸（"你好漂亮啊"会给对方压力）。
- **先给再要**——推荐个地方、帮对方拍张照、逗对方笑一下——然后提个小请求，再约。道谢点到为止。
- **争取早点让对方笑。**
- **结尾要么约好，要么加上微信**，别只说"很高兴认识你"。（加微信时你来扫对方或者让对方扫你都行，自然一点："加个微信，回头把那家店发你。"）如果没感觉，"很开心聊天"然后走人。
- **紧张就先热身：** 先找几个人问路，然后带着同样放松的状态去搭讪，除了聊几句没有别的目的。
- **心态：** 不成就不成。下一个。

## 3. 交友 App 和社交平台私信

- **开场 = 对方资料里的具体内容 + 一个钩子或问题**，别只发"你好"。"第三张照片背后肯定有故事，说说" / "有争议：你说的[对方的观点]是错的，我能证明"。
- 回应对方真正写的内容，并且给出你的看法，别只抛问题。
- 聊得不错几天内就约（见 `texting.md` §4）。探探、Soul、陌陌是用来约见面的，不是找笔友的。
- 从 App 换到微信要自然，聊得来再提（"这边不常上，加个微信？"），别一上来就要微信。
- 小红书 / 朋友圈互动：对一条笔记或动态留一句具体、轻松的评论；别一口气点赞对方二十条旧内容。

## 4. 聊天技巧

- **钩子-展示-释放。** 钩子："我刚回来。" 展示（对方接了的话）："跟朋友去了趟意大利。" 释放：换话题；对方不问就不展开。钩子没人接就换牌（换话题）。几分钟一个，别叠着用。
- **信息密度。** 回答要有内容，别只回两个字。
- **聊人，别聊流水账。** "你会做饭吗？" → 想象一个未来（你做饭，对方洗碗——谁更厉害？）。
- **别查户口。** 年龄、工作、老家连着问，就是人口普查。一个问题 + 一个反应："白羊座？嗯……白羊和双子一起自驾游能活着回来吗？"
- **关键词联想。** 抓住一个词往下发挥："幼儿园老师……那你要么是耐心无限，要么是表面温柔其实很凶。"
- **话题就在眼前：** 对方穿什么、刚说了什么、照片里有什么。
- **用"为什么？"往下追。** 逐步加深、双方对等的自我暴露，是拉近距离最可靠的方法。
- **夸得具体（"二阶反馈"）：** 夸 + 理由。"这个紫色特别衬你"胜过"你今天很好看"。留意那些对方特意花了心思、希望有人注意到的细节。
- **要有观点。** 偶尔友好地唱反调。价值观大概六成重合就足够了；什么都同意，等于没有自我。
- **幽默** 是最强的吸引力之一。夸张、角色扮演、回扣之前的梗。
- **闲聊和技巧穿插：** 大概一半是普通闲聊，每隔几句来一个调侃、钩子或小故事。
- **默认熟悉。** 像已经很熟一样说话，这种感觉会传染。

## 5. 调侃和"测试"

先分类对方说的是哪种：

| 类型 | 长什么样 | 怎么做 |
|---|---|---|
| **调侃 / 测试** | "你是不是对谁都这么说"、"你看起来很渣"、"证明给我看" | 放松。调侃回去、换个角度、笑一笑。 |
| **诱导你去讨好** | "男人都是嘴上说说"、"说服我" | 别开始自证。轻轻扔回去。 |
| **真问题** | "你还在跟别人聊吗？"、"你想找什么样的关系？" | 诚实、轻松地回答。 |
| **窗口** | 对方主动分享、问你的事、不想结束 | 往前推进。 |

应对轻度挑战的几招：
- **反弹：** "你怎么还不约我？" → "想我了？"
- **选 C：** 给你 A 或 B，你给第三个答案。"你觉得我下次去哪旅游？" → "跟谁去比去哪重要。"
- **重新定义标签：** "你好渣啊。" → "会聊天不等于渣。渣是骗人，我只是有什么说什么。"
- **反转裁判：** "你看起来就很会撩妹。" → "以貌取人？扣一分。"
- **笑着认了：** "你是在撩我吗？" → "不行吗？"
- **认同并夸张：** "你好奇怪啊。" → "官方认证的，有证书。"

规则：**调侃就调侃回去，真问题就认真回答。** 分不清是哪种，就诚实又轻松地回答——两种情况都能过。背下来的段子一旦被用烂就失效了；真正的安全感是被反复挑战还站得住，要练的是这个，不是背剧本。

## 6. 当面看兴趣

绿灯：眼神接触多、常笑、身体转向你、碰你胳膊、问你的事、跟你说话时玩头发 / 饰品、待得比原计划久、主动提下一站。黄灯：礼貌但身体姿态是关着的、挡开你的撩、频繁看手机或者看门口。红灯：回答很短、身体转开、提到要走了、你碰时往后缩。黄灯就放慢，红灯就保持友好、收尾。
