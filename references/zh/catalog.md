# 技巧大全（完整方法，已去重）

适用范围：中国语境下男生追女生（微信、朋友圈、交友 App、街头/社交场合搭讪、约会）。原始笔记里每一条不同的原则、技巧、判断方法、信号和话术都收在这里，按阶段分组。原文有中文说法的，直接用中文说法当标题。

证据 / 伦理标签：
- **[有研究支持]**：和亲密关系、说服心理学的研究结论一致。
- **[合理但未验证]**：听着有道理，但正反两方面都没有直接证据。
- **[与研究相反]**：证据指向相反方向，按后面给的修正版来用。
- **[操控性 → 诚实版本：…]**：靠撒谎、装人设、施压、无视拒绝、灌酒或绕过拉黑才能成立。原版不要教。教诚实版本，或者直接"不要用"。

压倒下面所有内容的教练原则：她说"不"、往后退、拉黑、删你，这些都是信息，不是测试。调侃就用调侃接，真问题就老老实实回答。

## 1. 心态与自我认知

- **女生不是追来的，是吸引来的**：力气花在把自己变好上，别花在死追某一个人身上。一个男生能把她的优点列一大串，自己的优点一条都说不出来，那就是"没有产品的推销员"。[合理但未验证]
- **显示器与主机**：话术只是显示器，显示的是你这台"主机"（性格、三观、生活方式）。没有哪句话能让人喜欢上你，她是从很多条消息里慢慢拼出你是个什么人。先把生活过好，再练话术。[有研究支持：驱动吸引的是对方感知到的特质，不是台词]
- **需求感是总开关**：几乎所有翻车都在释放同一个信号——"我很需要这事成"：秒回、长篇大论、连发好几条、一直解释、什么都附和、被拒了还反复约。[有研究支持，但要拿捏分寸：卑微、不自重确实减分。可是让她知道你喜欢她是加分的（互相喜欢效应），所以要砍的是需求感，不是热情]
- **情绪稳定 = 没有需求感**：别过度解读她几点回、发了什么朋友圈、给谁点了赞。别截她朋友圈去问兄弟"这是啥意思"。"回了就回了，不回也行。"[合理但未验证]
- **不怕、不给、不要**：不露怯，不过度付出，不表现得非她不可。[合理但未验证]
- **自我优先 / 自尊自重**：你的需要和她的要求冲突时，先顾自己。你累瘫了，就别半夜开车穿过半个城去找她："今晚真不行了，周四吧。"[有研究支持（自尊和边界感）。别变成故意装忙、玩消失]
- **项目第一，女生第二**：过你本来就会过的日子，然后邀请她进来，而不是围着她安排生活。[合理但未验证]
- **顺便**：把花时间、花钱说成你本来就要做的事（"我正好要去吃泰国菜，一起？"），这样你就不会惦记着要回报。[合理但未验证]
- **不要感动她**："感动不是喜欢。"对一个不喜欢你的人搞轰轰烈烈的付出，换来的是愧疚和亏欠感，然后你只能不停加码。[有研究支持：对方没要的人情只会让人觉得欠债，不会让人喜欢]
- **女生讨厌的五种男人**：以为对她好就能追到；觉得她跟别的女生都不一样；牺牲自己去讨好她；把她当女神供着；深情告白想感动她。[合理但未验证]
- **拒绝就是筛选**："她说有事（加班、考试），就是没选你，仅此而已。"真想见你的人会想办法绕过障碍。别跟借口较劲。[合理但未验证。有时借口是真的，允许她真诚地改一次时间]
- **接受不被喜欢你才自信**：接受有些人就是不会喜欢你，你反而自信了，喜欢你的人也就多了。[合理但未验证]
- **选择多了，需求感自然降**：多和人接触，对每一个人都会更淡定。[合理但未验证。诚实版本：她问起你是不是也在认识别人，照实说。原版那套"一天聊 10 个以上 → 进入冷淡'贤者模式' → 她们反过来追你"属于操控性 → 诚实版本：多认识人，让任何一个结果都不至于决定你的心情，但别演高冷]
- **享受使用权，不要在意拥有权**：刚开始别表现出占有欲，她可能也在接触别人。[合理但未验证。把"使用权"这种把人当物件的说法去掉]
- **一开始别亮目的**：刚认识就别说要结婚，也别亮任何目的，"有目的就会给她压力"。很多男生都是真心的，但不给她压力的没几个。[合理但未验证]
- **心态大于话术**：让人觉得你猥琐，解决办法是改变你对这次互动的理解（这就是两个平等的人正常社交），而不是背台词。"意外不可怕，应激行为才可怕。"[合理但未验证]
- **预案库**："所有临场发挥，都是提前设计好的。"约会前先把故事、常见问题的回答、话题分支练熟。[有研究支持：提前演练能降低焦虑。操控性 → 诚实版本：只练真实经历，别编人生]
- **十年视角（长期 vs 短期）**：短期好感可以靠钱、颜值、人设买到；长期看的是你的底子。装出来的特质迟早露馅，就像实物跟买家秀对不上，最后被退货。长期的基础是：真实、性格，还有"让人看得到希望的品质"（潜力）。[有研究支持]
- **潜力股**：穷不可怕，可怕的是看不到上升的趋势。跟昨天的自己比，读书、健身、练表达。别抱怨。[合理但未验证]
- **心力与运气**：大结果一部分靠运气，但你得一直在场上才接得住运气。"重要的是心力，不是能力。"[合理但未验证]
- **圈子**：身边是什么人，影响你往哪走，也影响别人怎么看你。多跟能把你往上带的人待在一起。[有研究支持。原文"远离穷父母"那句去掉]
- **别为她改变，为自己改变**：吸引喜欢真实的你的人，而不是把自己捏成一个"四不像"。[有研究支持]
- **交换思维**：感情、工作、找导师，本质上都是互相提供价值。不肯投入（健身、技能、赚钱）却想要结果的人，就是"想白嫖"。[合理但未验证]
- **舔狗的来源**：讨好型人格往往跟成长环境有关：有条件的爱、打压式教育、"听话 = 好孩子"。看清它，不怪父母，重建自己的配得感。[有研究支持：条件化自我价值、焦虑型依恋]
- **普信男的重新定义**：让人反感的不是普通又自信，而是怨气：骂女生物质，把别人的成功都说成运气或有钱。[有研究支持：敌意很减分]
- **反二极管思维**：吸引力不只是颜值和钱。幽默、生活丰富、情绪稳定、会做饭、敢冒险、情商，都算数。不同女生看重的不一样，要看人下菜碟。[有研究支持]
- **不管对错，只看强弱**：这条说"对不对不重要，稳不稳才重要"。[与研究相反（作为恋爱规则：防御和轻蔑是分手的预测指标）。只保留一点：别为鸡毛蒜皮的事吵，保持冷静]
- **畏惧之心 / 位置**：说什么女生"不敢碰你手机"才说明她尊重你。[与研究相反；靠恐惧换来的顺从，是控制型关系的特征。不要用]
- **"女生都是 X"（慕强、"7 天记忆"、"99% 靠情绪"、"没有慢热的女生，只有不喜欢你的女生"）**：一刀切的本质论。[与研究相反。最多当成对某个具体的人的经验判断。"没有慢热"有一部分有用：拖了很久一点热度都没有，通常就是没戏]

## 2. 形象与线上资料

- **展示面**：穿着、照片、朋友圈是第一道门槛。展示面不过关，聊天再会也救不回来。[有研究支持：照片带来的第一印象影响很大]
- **显贵**：要显贵，不是显帅。面料质感 > 品牌 > 款式。素色、合身的黑白，赢过大 logo 和花里胡哨的图案。[合理但未验证]
- **三分长相七分打扮**："整体帅"靠的是穿搭、体态、说话、眼神和发型，不只是五官。[有研究支持：打理和穿搭能明显拉高评分]
- **香水**：一瓶好闻的香水，是成本最低的生活品质信号。[合理但未验证]
- **打理和小动作**：鼻毛、缩水的衣服、手上小动作、抖腿、身体晃来晃去，都显得紧张。动作越少越有气场。保持眼神接触。[有研究支持]
- **身材**：有点肌肉就行，不用练得太夸张。[合理但未验证]
- **朋友圈内容**：发真实的生活（运动、做饭、旅行、朋友、工作），整体积极。不发伤感语录、不抱怨、不吐槽发泄。[合理但未验证]
- **朋友圈重建**：在重新联系一个已经冷掉的人之前，换头像和昵称，删掉以前尴尬的动态，然后连续 6–7 天发你真实在做的事。[合理但未验证。如果是编造生活就属于操控性 → 诚实版本：只发真实的活动。绝不能为了绕过拉黑或删除去重建资料]
- **蒙太奇展示法**：一趟旅行拆开发好几个月。[操控性 → 诚实版本：按真实节奏发真实生活；见面时对不上，代价更大]
- **拿网图或旧图当"证据"（饭菜、狗、红酒、银行贵宾厅、"刚打完网球"）**：[操控性 → 诚实版本：拍你此刻真实在做的事，或者干脆不发。不要用]
- **硬价值 / 软价值**：硬价值（钱、颜值、身材、地位）决定你能匹配到什么层次的对象，是你"上场"的门票；软价值决定你能不能赢。硬价值越高，容错空间越大。[合理但未验证]
- **软价值清单**：[幽默、自信、善良/稳定、热情 有研究支持；其余合理但未验证]
  - *预选*：有别的女生喜欢你、认可你（马太效应）。意思是你在社交上受欢迎，不是让你去广撒网。
  - *事业*：做自己在乎的事，哪怕不起眼（"一个热爱工作的幼儿园老师"）。
  - *圈子*：有质量的朋友。别展示低端或者满身戾气的朋友。朋友可以当僚机。
  - *才华*：是画龙点睛，不是发动机。
  - *能量*：积极，线上线下都不抱怨。
  - *自信*：跟长相无关。抓住一个真实的长处，别老盯着短板。
  - *稳定性*：不被她发的朋友圈、回消息快慢、点赞带着走。
  - *幽默*：背后得有价值撑着才好笑，不然你就是"耍猴的"。
  - *领导力*：能拍板、会安排，她跟着就行。
- **价值感**：重要的是她感受到的价值。[合理但未验证。如果意思是虚报，就属于操控性 → 诚实版本：把真实的价值好好展示出来]
- **信息差爱好**：看着贵、其实不贵的爱好（打高尔夫练习场大概 ¥100–200）。[作为聊天素材：合理但未验证。你真玩才行；别拿来暗示自己有钱]
- **亮出能吸引你想要的人的那一面**：炫富吸引拜金的；生活方式和人品吸引看重人的女生。钱要让人看出"不穷"，而不是拿来炫。[有研究支持：炫耀性消费传递的是短期意图]
- **车**：别拿车去追人。超跑吸引来的是不对的兴趣，还会吓跑想过日子的女生。要开车的话，中档轿车显得成熟。打车反而让注意力留在你身上。"你穷的时候喜欢你的女生，是真喜欢你。"[方向上有研究支持]
- **包装身份**：用最体面但真实的说法介绍工作没问题。把外卖骑手说成"自媒体创业者"就不行了。[操控性 → 诚实版本：如实说你在做什么，说得有热情一点]
- **App 上的门槛问题**：App 要你回答她设的筛选题（"描述一下你理想的恋爱"）时，别写一段千篇一律的浪漫场景。给一个真实的观点（"说实话，人比场景重要"）。[合理但未验证]
- **前三句诊断**：前 3 条消息她都不回，问题出在你的照片/资料，不是聊天。[合理但未验证]

## 3. 搭讪 / 开场

### 线下
- **破除防备**：她第一怕的是推销的，或者缠着不走的。给个时间上限就能打消："能占用你 30 秒吗？" / "就 3 分钟"。[有研究支持：降低对方感知成本能提高答应率]
- **别说"我不是推销的"**：这句话一出口就像推销的。直接快速说你是谁。[合理但未验证]
- **给个理由**：带理由的请求，哪怕理由很单薄，答应率也更高。诚实说法："我想在这拍张照，你一看就很会构图，能帮个忙吗？"或者"刚看到你，想过来打个招呼。"[有研究支持]
- **引起注意 → 描述状态 → 要微信**：三步开场。先引起注意，再描述当下的情况（"我刚从那边走过来，看到你……"），然后要联系方式。别一上来就"你好有气质"。[合理但未验证]
- **提供价值再索取**：先给点东西（也帮她拍一张、帮她修图、推荐个地方），再提个小请求。[有研究支持：互惠]
- **先求助再回报**：她帮你一个小忙，你回一个很小的人情（一杯 ¥10 的奶茶，不是火锅），一起待一会儿就有了自然的理由。对陌生人搞大手笔，只会让人觉得是坑。[有研究支持：登门槛效应]
- **互相报答那句**："关系不就是互相报答才能拉近吗。"[合理但未验证。当玩笑说，别变成义务]
- **挑人**：挑有时间、状态放松的人（在景点自己拍照的、在店里闲逛的）。穿着工服急着回家的就别打扰了。[合理但未验证]
- **先观察**：看一会儿，推断她是什么状态（一个人旅游、下午没事），再调整说法。[合理但未验证。别跟着人、别在旁边晃悠]
- **尽快让她笑**：前几句没让她笑，她就走了。把好玩的放前面。[合理但未验证]
- **问路练胆**：先找个男生问路，然后马上用同样放松的状态去找女生说话。把让你僵住的"目的感"去掉。[合理但未验证；暴露练习本身有研究支持]
- **不在乎结果**："不行就下一个。"做好失败的准备；别的教练看着像神，是幸存者偏差。[有研究支持：暴露练习]
- **坦白目的**："我绕了这么一大圈，其实就是想要你微信"——如果你这人好玩，这么说效果反而好。"人好玩，亮目的没事；人卑微或者无聊，亮目的就是找死。"[合理但未验证]
- **不带目的的欣赏**："人希望被喜欢，不希望被索取。"你可以表现出喜欢她，只要你不是想从她身上拿什么。[有研究支持]
- **沉稳 + 别烦别人 + 别索取 + 脸皮厚**。[合理但未验证。脸皮厚指的是被拒绝扛得住，不是被拒绝了还纠缠]
- **假身份借口（旅游博主、vlogger、"街头魔术师"、"生活记录者"、帮朋友挑礼物、"采访送小礼品"、粉丝数、认识某某网红）**：[操控性 → 诚实版本：用你真实的理由。"觉得你气质挺好，想打个招呼"或者真心请她帮忙拍照。不要用]
- **顶级阳谋 / 打赌**：设一个怎么输赢你都能约到她的赌（"我要是没有 500 万粉丝，请你吃一个月饭"）。[建立在假话上就属于操控性 → 诚实版本：真实又好玩的赌（"三次之内猜中你星座，甜品店你挑"）]
- **借热点 / 借充电宝 / 解锁手机"魔术" / 拼桌这类借口**：[操控性 → 不要用。解锁手机那招是在没有真正同意的情况下把自己加进她手机。诚实的拼桌：直接问，说好"5 分钟"就守信，别挪到她那边去坐]
- **假装崴脚求扶 / 求接触**：[操控性 → 不要用]
- **求她留下（"求求你了"）**：[操控性 → 她拒绝了，就道谢走人]
- **替她做决定 / "犹豫了就是同意"**：[操控性 → 诚实版本：她答应之后，由你来安排细节。犹豫不等于同意；问清楚，接受她说不]
- **猜谜换微信**："我猜三次你的星座/职业，猜中了就加个微信。"[合理但未验证。她明显愿意玩才行；别用道具"逼"她，也别耍花招]
- **冷读**：从细节判断她的性格（"外冷内热"、"你是那种看到受伤的流浪猫会带回家的人"）。至少有 80% 把握再说，不然很傻。[合理但未验证。坦白说你是在猜]
- **留点念想**：搭讪结束时留个计划或承诺（"我今晚给你发消息"）。她要是问"那我等多久？"，是很强的正面信号。[合理但未验证]

### App / 社交平台
- **极简开场**："hi"、她的名字，或者一个表情。不说"美女"，不说"在干嘛"，不用"你长得好像我一个朋友"那种套路。只发一个表情，顺便也测出你的资料有没有过关。[合理但未验证]
- **尽快换平台**：App 随时可能被解除配对。用一句短话转到微信（"这 App 太难用了，加个微信"）。[合理但未验证]
- **说她像她喜欢的明星**：她朋友圈里有喜欢的明星，说她长得像（限颜值型偶像，不是实力型），很好用。[合理但未验证。"改备注 + 截图"那个小把戏，如果感觉像套路就别用]
- **话题从她资料里找，别从你脑子里找**：看她的照片、表情、最后一句话，大概 3 秒内找到评论点。"凭空编话题，最后就变成查户口。"[合理但未验证]

## 4. 聊天功力

- **吸引 → 拉升 → 邀约**：先吸引，再拉近关系，再邀约。聊天大概占一半，约会占另一半。[合理但未验证]
- **油腻 = 跳环节**：第 N 阶段的话放到第 N−1 阶段说，就是猥琐。同样一句话从老公嘴里说出来就是甜。翻车的时候，问问自己跳了哪一步。[合理但未验证；符合逐步自我暴露的社交规范]
- **态度 / 行为模式**：重要的是态度，不是内容。陈述，别乞求。"下周末一起吃个饭"对比"能不能给我一个机会？"；"我一般不下厨，看你表现吧"对比急吼吼地吹自己。[合理但未验证]
- **言简意赅**：去掉废话和语气词（"在干嘛"而不是"在干嘛呀"；"看电视"而不是"我在家看电视呢嘿嘿"）。语气偏冷一点，少用呀/呢/吗。[合理但未验证]
- **钩子-展示-释放**：抛钩子（"我也才刚回来"），展示（"跟朋友去了趟意大利"），然后换话题。来回 3–5 轮能把好奇心吊起来。据说上钩率 ~60%（"刚回来"能到 80%）。[合理但未验证]
- **换牌**：一个钩子她不接，就换一张"牌"（网球 → 做饭的故事）。大概 4 次都没接，而其他好感信号还行的话，就别再抛钩子了。[合理但未验证]
- **别连环展示**：展示一次，接一句玩笑或者一个问题。连着展示就像孔雀开屏，显得求认可。[合理但未验证]
- **平A加技能**：大约 50–60% 的时间正常闲聊，每 3–5 句插一个调侃、钩子或者故事。[合理但未验证]
- **四类话题**：筛选（筛她）、展示（展示自己）、调侃、闲聊。自黑被移出了清单，因为拉低身份。[合理但未验证；研究里轻度自黑没问题，重度不行]
- **信息密度 / 抛钩子**：别两个字就回完。"东北的" → "东北的，所以我滑雪橇莫名很强，吃辣就是废物。""她问的任何问题，都用一个故事来答。"[有研究支持：展开说能提升好感]
- **不要聊事要聊人**："你会做饭吗？"比"吃午饭了吗？"强。做饭能引出对未来画面的想象（你做饭，她洗碗）。[合理但未验证]
- **别查户口**：年龄、工作、老家一连串问下来就是人口普查。问一个问题，然后接住它（"白羊座？白羊和双子合得来吗？"）。[有研究支持]
- **筛选 / 反筛选**：问问她能带来什么（"你会做饭吗？"），别光展示自己。这是邀请她投入。别连着筛两次而自己什么都不给。[合理但未验证]
- **引导追逐**："那你觉得我是个什么样的人？"她在脑子里给你画像，投入也就更多了。[合理但未验证]
- **刨根问底**：她自己提起的话题，用"为什么？"往下追。是她起的头，就不算审问。[有研究支持：双方逐步加深的自我暴露能拉近关系]
- **好奇撩法**："真的假的？然后呢？不会吧！"让她继续往下说。[真心好奇时有研究支持。装出来就属于操控性 → 诚实版本：只问你真感兴趣的]
- **关键词联想法**：从她提到的一个事实出发，想象画面，落到情绪上（"幼儿园老师" → 很有耐心，还是私下其实很严？心软吗？）。瞄准感受（孤独、浪漫、开心），别聊流程和工资。[合理但未验证]
- **看话题，右脑**：从眼前找话题：她的戒指、头发、口红、周围环境。知识储备只用来增色（"三亚的海和青岛的海"）。[合理但未验证]
- **记住她说过的细节**：把她之前说的话拿回来用，是加分项。[有研究支持：被感知到的回应度]
- **从一个字读情绪**："又开心了"——这个"又"说明她之前心情不好。[合理但未验证]
- **二级反馈 / 夸不是捧**：夸 + 理由："瘦了？脸的线条出来了，紫色也很衬你。"人会故意留细节等着被发现。笼统的吹捧（"你穿什么都好看"）就是舔。[有研究支持]
- **侧面夸 / 变相夸赞**：通过一个理由或者第三方来夸（"好看的人拍照怎么都好看"、"老板多给你一份是因为你好看"）。少用，别每句都来。[合理但未验证]
- **不带主语的夸**："漂亮的女生经常被搭讪，真正好看的反而没人敢。"给自己留了个俏皮的退路（"我又没说是你"）。[合理但未验证]
- **变相夸自己**：别光把她往神坛上捧。"你得试过才知道，不然就错过了。"[合理但未验证]
- **夸张、开玩笑式的夸，胜过畏畏缩缩的夸**：畏畏缩缩、目的又很明显的夸，显得卑微。[合理但未验证]
- **独立观念**：对价值观、男女分工、钱有自己的看法，不同意也能好好说。有 ~60% 重合就够了。"君子和而不同。"筛掉不合适的人是好事（宁缺毋滥）。[有研究支持]
- **不辩解缺点**：她拿你的身高、体重开玩笑，就往你的长处上带（"我的属性点都加在智力上了"）。[合理但未验证]
- **调侃**：在放松的状态下轻轻调侃。别太重，她不笑了就停。[合理但未验证]
- **推拉**：一句话里又夸又损（"是不是好看的女生都看脸？"）。光损 = 吵架；光夸 = 舔狗。[少量用：合理但未验证；当成策略来用，见第 7 节关于间歇强化的说明]
- **神秘感**：别一下把底牌全亮了。早期的吸引有一部分是她自己的投射。"我还有别的工作，剩下的你以后会知道。"[合理但未验证；长时间隐瞒基本信息，和自我暴露的研究结论相反]
- **暗示人设**：用故事来展示特质，就像魔术师先撸起袖子。永远别说"我不是渣男"，一说就像。[合理但未验证]
- **吹牛找契机，点到为止**：话题给了口子才吹（"你能吃辣吗？" → "我经常到处跑"），一两句就停。[合理但未验证]
- **释放可得性 / 铁汉柔情**：吸引有了之后，要让她觉得你是够得着的（"就上班呗，说实话没那么忙，也没女朋友。"），再露一点居家柔软的一面（狗、做饭）。硬价值太多反而显得高攀不起。[合理但未验证]
- **偏爱 + 高标准 / 唯一性**："我不是对谁都这样"配上"我挺挑的"。只说前一句像舔狗（"只有你"），只说后一句像中央空调。[有研究支持：有选择的喜欢，比对谁都喜欢更受欢迎]
- **第一次**："我从来没为谁这样过。"[是假话就属于操控性 → 诚实版本：真的才说]
- **第三人称拉升**：把"你俩很合"归到算命的、塔罗或者路人头上（"有个算命的说……"）。降低你看起来的需求感。[合理但未验证]
- **暗示性邀约 / 埋期待**："改天给你做饭，看你表现。"[合理但未验证]
- **语言禁摩**：用语言描述身体接触，而且让她当动作的发出者（"你会打我吗？"而不是"我打你哦"；"过来给我捏捏肩"，不说"我给你……"）。要短，别带表情，而且只在她明显喜欢你之后用。[合理但未验证]
- **反过来说**：把想要的东西用否定方式说出来，降低需求感（"我很少陪女生逛街"）。[合理但未验证]
- **前任话题**：讲一个简短的故事，或者表个态。绝不说前任坏话；也别盘问她的前任。绝不贬低别的女生。[有研究支持]
- **不聊第三者**：调情的时候，别聊别的男生，也别聊你在接触的别的女生。[合理但未验证]
- **同病相怜**：对一个防备心重的女生，真实地说说你自己受过的伤，能让她放下防备。[是真的就有研究支持。根据她的倾诉编出来就属于操控性 → 诚实版本：只分享真实经历]
- **装傻（"你骗我我也信你"）**：[当玩笑：合理但未验证。别把它变成一种人设]
- **知识面打法**：没去过的地方，看过资料也能聊，但要说"好想去"，别说"我去过"。[合理但未验证；只有这样说才算诚实]

## 5. 测试 / 挑战

- **每句话先分类：测试 / 引导 / 窗口**：测试是看你会不会慌，保持放松就行。引导（引导跪舔/引导自证）是想让你证明自己，轻轻抛回去。窗口是她真的在打开，往前走。[合理但未验证。教练原则优先：真问题就给真回答]
- **调侃用调侃接，问题用真话答**："你在跟几个人聊？"如果她是认真问的，就该直接回答。拿不准的时候，诚实又轻松地答，两种情况都能过。[有研究支持：防御心伤关系，诚实建立信任]
- **不解释 / 不自证**：她轻轻调侃一句，你回一大段焦虑的辩解，只会显得没底气。[针对防御心：有研究支持。理解成"什么都不解释"就与研究相反]
- **反问**："你怎么还不约我？" → "想我了？"[合理但未验证]
- **选C / 跳出框架**：她给你 A 或 B，你给第三个答案。"我下次去哪旅游好？" → "跟谁去比去哪重要。""要奖励还是惩罚？" → "要一段回忆。"[合理但未验证]
- **抛框架**："你是在撩我吗？" → "我从不撩人，我只是跟着感觉走。"[合理但未验证]
- **大胆承认**："你是在撩我吗？" → "不行吗？"真的事就别否认。[有研究支持：坦诚]
- **抛出定义**："你是个渣男" → "会说话不等于渣。渣男是骗人，我只是说我想说的。"[合理但未验证]
- **反将一军**："你看着就像经常撩妹的" → "以貌取人？扣一分。"然后："你是好奇我做什么工作，还是好奇我专不专一？"[合理但未验证]
- **用价值观回应**："这么快，还说自己不随便？" → "随不随便不看快慢，看挑不挑。""同样的事，你觉得是撩，我觉得是浪漫。"[合理但未验证]
- **不缺 + 挑**："你缺女朋友吗？" → "不缺不代表随便。"[合理但未验证]
- **"你喜欢什么类型？"**：别说具体类型。"没有固定类型，看相处。" / "标准是给不喜欢的人定的。"[合理但未验证]
- **"让我喜欢你啊" / "男人都是嘴上说说" / "证明给我看"（自证陷阱）**：别列自己的优点。"你慢慢体会。""你之前都遇到些什么男人啊？"[合理但未验证]
- **"你猜"**：可以不猜："我直男，读不了心，你得告诉我。"[合理但未验证]
- **"你上一段感情结束多久了？"**：别直接报个数（太短 = 还没走出来，太长 = 没市场）。"改天喝一杯的时候告诉你"顺便还是个软邀约。或者往上一层说："不在于多久，在于放没放下。"[合理但未验证。她是认真想知道，就告诉她]
- **"你搭讪/加过多少女生？"**：调侃的语境下回"怎么一上来就问这个？"没问题。原版说"就你一个"，如果是假话就属于[操控性 → 诚实版本：轻松地说句真话（"不多，也不是常干这事"）或者"吃饭的时候问我"]
- **能干不能认**："你好会说话 / 你好会撩" → "我不会说话，我只是挑。"[是假话就属于操控性 → 诚实版本：笑着带过，别装纯（"在你身上练习呢"）]
- **受害者切换（"我也怕受伤"）**：[用来降低她的防备就属于操控性 → 诚实版本：真的这么想才说]
- **转移嫌疑**："你以前受过伤？" → "那说明你的直觉也没那么准。"[当成习惯就与研究相反（转移话题让人不信任）。最多当个轻松玩笑，绝不能拿真实的伤开玩笑]
- **被逼问时给客观理由**："你带别的女生来过这吗？" → "这家才刚开。"[合理但未验证。必须是真的]
- **二选一和"谁更好看"陷阱**：用幽默把两个选项都推掉。[合理但未验证]
- **把她的每个要求（点外卖、发红包、问生日、要你唱歌）都当成测试**：[与研究相反。大部分要求就只是要求；按实际情况答应或者拒绝]
- **她迟到算不算测试，你迟到怎么办**：见第 12 节。
- **高价值女生测试很多**："一百次测试，挂一次就出局。"[合理但未验证，说得夸张了；有用的核心是保持镇定]

## 6. 微信聊天与节奏

- **聊天只有一个目的：邀约**：聊了 3 轮以上还没约，流程就错了。流程对的话，3–7 天就够，不用几个月。[合理但未验证]
- **跑道**：100 米跑道，前 50 米吸引 → 中点窗口（临界点）→ 后 50 米拉升 → 邀约。[合理但未验证]
- **长度**：每条消息 ≤2–3 行（≤2 段）。一次聊天控制在 ~10–20 个来回，永远别超过 30 行。大概 20 个来回通常就足够建立吸引。从开聊到邀约，整个过程可以压在 ~30 行以内。[合理但未验证]
- **例外：真诚聊法**：对没安全感或者被伤过的女生，长一点、软一点、真诚一点的消息比斗嘴好用。"字越多，越显真诚。"[合理但未验证]
- **一次追逐原则**：她不回，过几个小时可以再跟一条。然后就停，复盘哪里出了问题，调整好再说。[有研究支持：对方沉默后还一直追，会被当成施压]
- **别连发**：发一条，然后等，她多久回都等。过度解读沉默，暴露的是不配得感。[合理但未验证]
- **重启前先等**：没回的话，等到第二天（一般 ~48 小时），再发一个简单的"hi"或者表情。同一天别发好几条。[合理但未验证]
- **跟她的节奏**：她隔 50 分钟回，你没必要 30 秒就回。隔一天也没事。"正常"的节奏，好过秒回，也好过故意晾着。[有研究支持但有细节：回应度推动亲密感。她已经热起来了你还故意长时间晾着，属于操控性 → 诚实版本：有空就回，自然节奏]
- **顺位**：她在打游戏、开车、拍东西的时候，你是第二顺位。等她有空。[合理但未验证]
- **观察她的窗口期**：留意她通常什么时候回得最积极（比如晚上 9 点到 9 点半），就在那时候发。[合理但未验证]
- **打游击**：对一个冷掉的联系人，发一条短的就撤，别"打持久战"。[合理但未验证]
- **高点撤离**：聊得正开心的时候走，像电视剧的结尾悬念。有时候让她发最后一条。要是她总是看着你的消息睡着了，"不回"就会变成习惯。[合理但未验证]
- **冷场不用填**：信息量很低的回复（"嗯"、一个表情包）不用接。换个新话题，或者就先放着。[合理但未验证]
- **别按需供应话题**："好，你开始吧" / "那你说啊"——把尴尬直接说出来（"这让我怎么接？"），让她来填。[合理但未验证]
- **用词决定她的下一个问题**："我出去 3 天"→ 她问去哪；"出差 3 天"→ 她问你做什么的。一句话可以带两个钩子。[合理但未验证]
- **发照片代替描述**：发一张你正在做的事的真实照片（遛狗、自己做的饭），比嘴上说更能展示生活。[合理但未验证。必须是真实的、当下的]
- **不报备**：不用每次不在都跟她汇报。[合理但未验证。正式在一起以后，正常礼貌比这条重要]
- **晚回顺便展示价值（隔 40 分钟回"刚刚遛狗呢"）**：是真的就没问题。[合理但未验证]
- **以牙还牙**：她不理你，你也别追；第二天再开个头。[合理但未验证。当成惩罚来用就属于操控性 → 正常地重新开一次头就行]
- **无痕测试**：故意不回，看她会不会来追。[操控性 → 诚实版本：轻松地问一句，或者直接观察她会不会主动找你]
- **别太早打语音，别每条朋友圈都点赞**：低调存在，好过时时刻刻刷存在感。[合理但未验证]
- **别用她的词**：她说你在"泡"她，你别顺着用这个词。[合理但未验证]
- **文字里远程拉升**：语言禁摩、俏皮的昵称、第三人称说合拍、"那你得给我做饭"。[合理但未验证；留意她的反应]
- **要照片**：别要腿照、身材照、洗澡照。[操控性/施压 → 不要用。她自己发了，温暖地回应，但别得寸进尺]

## 7. 判断好感（窗口 / 黄灯 / 红灯）

- **窗口是什么**：她明显在打开的那一刻。窗口很短（"像流星雨"），当天就要动。离上次联系越久，窗口越小。[合理但未验证]
- **文字窗口信号（完整清单）**：[作为清单：合理但未验证；回应度和自我暴露类信号有研究支持]
  1. 回得变长了，还带着可有可无的废话（"我刚毕业出来在当牛马呢"对比"牛马"）。
  2. 用软化语气词、叠词（呀/呢/吗；"嗯嗯"对比"嗯"；"哦哦"对比"哦"）。
  3. 有反应词（哇、真的呀、是吗）和笑（"哈哈哈"、"天哪真的假的"）。
  4. 表情变多。
  5. 主动跟你说她的状态和日常（"好累"、"怎么还不下班"）= 有分享欲（轻度好感）。
  6. 她开始问你问题，尤其是问你的工作和生活。
  7. 她跟你解释、为自己辩解（自证）。
  8. 她问你叫什么（大窗口）。
  9. 你没出现，她半开玩笑地不满（"你消失了？"、"你失宠了"、"我们是有时差吗？"）。
  10. 她开始模仿你的说话方式。
  11. 她跟你说私事（身体、健康、计划）= "超级窗口"。
  12. 她主动发照片。
  13. 她问"你是在约我吗？"或者暗示（"有点饿了"）。
  14. 拒绝得很软，还带个追问（"你今天不上班吗？"）= 门还开着。
  15. 她说你"高冷"。
  16. 沉默一段后她主动找你，或者回得越来越快。
  17. 你说会给她发消息，她问"那我要等多久？"。
- **三种窗口情绪**（只在有其他绿灯信号时才算；害羞地*接话*是窗口，对一个请求犹豫、回"不确定"不是——永远别把犹豫重新解读成害羞）：害羞（被一句撩人的话弄得脸红，而不是抗拒）、顺从（跟着你的节奏走，接受你的安排）、索取（要关注、要认可："你怎么不给我发消息？"、"我跟她谁好看？"、给你发猫的照片、发饭的照片）。[合理但未验证]
- **线下窗口信号**：眼神接触、摸头发、舔嘴唇、看着你喝饮料、回话变长、笑、身体往前倾、你的手靠近她的范围她不躲、把离你最近那只手上的包挪开、为了多待一会儿取消别的安排（比如不去做美甲了）、问你晚上干嘛。[总体上有研究支持（非语言的接近信号）]
- **看情绪不看内容**："是我的就是我的"用很暖的语气说出来，可能是好感；她冲你有强烈情绪（因为你没回消息而生气），说明你在她心里有分量。[合理但未验证。绝不能拿来套在真正的拒绝上]
- **看她做了什么**：回不回、主不主动、来不来见面，比她说什么更准。[有研究支持]
- **黄灯**："哈哈你是在撩我吗？"或者岔开话题 = 放慢，不是前进。[作为警示：有研究支持]
- **红灯**："哦"、只回一个问号、不回、一直很短、明确说"不"、解除配对、删好友、拉黑、身体接触时往回缩、拒绝两次。[有研究支持：当成停止信号]
- **反信号：好处照收，亲近就挡**：所有好处都不要，说明她没兴趣。礼物和人情都收，但一提关系就绕开，那是在利用你。别再给了。[合理但未验证]
- **激烈情绪 vs 冷沉默**：已经在一起的关系里，她生气说明她还在投入。冷处理、拉黑才是真要走。[合理但未验证]
- **警惕无法证伪的解读**：如果她说"好"和说"不"你都当成有好感，那你已经不在听她说话了。[有研究支持]
- **"她的窗口可能是测试" / "拒绝是矜持"**：[与研究相反：大部分拒绝都是真心的。不要用]
- **别过度解读情绪**：很多表现就是普通的状态（累了、生理期、没睡好）。想太多会滋生需求感。她状态不对，就给点空间。[合理但未验证]

## 8. 邀约

- **模糊邀约**："改天小酌一杯" / "空了约杯东西"。她反应热，再跟一个具体计划。太早被硬拒，拒绝可能会变成她的习惯。[合理但未验证]
- **先确认她有没有空**：邀约前先问"明天干嘛呢？"，免得一头撞上拒绝。她忙就算了。[合理但未验证]
- **再具体（下指令，而不是请示）**："明天晚上 7 点吃日料？我知道一家。"再发个定位。一个清楚的计划，比"你什么时候有空？"更容易答应。永远别问"你忙吗？"或者"你想去哪都行"。[有研究支持：具体的计划提高落实率。保留一个问号或者"你要是有空的话"，让它仍然是邀请]
- **假定成交**：把计划说得像已经定了（"明天让我看看最好看的你"）。[她已经答应了的话：合理但未验证。用来跳过她的回答就属于操控性 → 诚实版本：先确认她答应了，再由你安排细节]
- **顺便邀约**："我正好要去看衣服，来帮我挑挑"，"我正好要去吃泰国菜"。双方压力都小。[合理但未验证]
- **地点让她挑，时间你来定**：（"7 点左右"）；她小小还个价（"8 点？"）就答应。[合理但未验证]
- **安排上的稀缺感**："我 5 点去接你。我一般不接人的。"[是真的话：合理但未验证]
- **小条件**："穿好看点。"[合理但未验证；轻松地说，绝不是控制]
- **"人生需要一点突然"**：用"说走就走"的感觉来约第二天。[合理但未验证]
- **喝酒的顾虑（"我不能喝酒"）**："喝果汁就行，主要是聊天。"[照这么说：有研究支持，尊重她的选择。绝不往喝酒上引]
- **约一群人或带一对情侣**：对防备心重的女生，邀请她加入一个有情侣在的小团体，风险感更低。[合理但未验证。如果是在掩盖过夜的目的（"住胶囊旅馆，反正你也可以回家"）就属于操控性 → 诚实版本：计划和住宿安排提前说清楚]
- **对地点卖关子**："你会喜欢的。"[合理但未验证；她问的话就告诉她，为了安全]
- **约会时给下次埋个钩子**：打个赌，或者定个计划（"明天去坐过山车"），自然就有下一次。[合理但未验证]
- **短期来玩的人**：问她在这待几天、今晚有什么安排，然后马上约，围着她已有的安排来（"你跟朋友吃完饭，要不要一起吃个夜宵？"）。[合理但未验证]
- **释放压力 / 给空间**：她有顾虑时："你朋友会替你开心的。""想来就来，没压力。"抓得越紧，越容易溜走。[合理但未验证]
- **轻松幽默化解**："这么快？" → "那等 30 年吧，等你成老太太了我带你去买菜。"[合理但未验证]
- **别一次次迁就她和朋友的安排**：提议换个时间。[合理但未验证]
- **事不过三**：她明确拒绝两次，或者最多约三次，就停，让她来主动。第二次约被拒，通常说明她基本是冷的。[有研究支持：尊重拒绝]
- **制造冲突触发损失厌恶（"本来今天想约你，结果临时有事"）**：[操控性 → 诚实版本：想约就直接约]
- **编出来的门槛（"要是我不开会的话"）**：[是编的就属于操控性 → 诚实版本：只说真实的限制]
- **上保险（"饮料点了吗？"、"出门了拍张照给我"）**：[用来把她锁死就属于操控性 → 诚实版本：正常确认一下"8 点还 OK 吧？"]
- **道德绑架（"只有坏人才会预谋浪漫"）**：[操控性 → 不要用]
- **逼单 / 下最后通牒（"给我房间号，不然我回家了"）**：[操控性 → 不要用。施压换来的是顺从，不是想要]
- **凌晨 2 点找喝醉的女生要"定位"**：[操控性 → 不要用。她喝多了，就帮她安全回家或者叫她朋友来，等她清醒了再聊]
- **"红酒网图，那你是让我白跑一趟？"**：[操控性 → 不要用]

## 9. 约会

- **前 30 秒**：准备一个能让她笑的开场（"第一印象就像第一道菜"）。[合理但未验证]
- **别像服务员一样迎宾**：别一下子站起来喊"欢迎！"。稳一点、沉一点。放慢，可以有安静的时刻。[合理但未验证]
- **带领 / 导游模式**：地点、路线、点菜你来定。只问她偏好（"甜的还是辣的？"）。一直跟着别人走的人没魅力。[作为体贴的安排：有研究支持]
- **点菜你来，两个人看一个手机**：避免两个人各自盯着自己手机。"我来点，难吃的话我带你去看电影。"[合理但未验证。尊重她的过敏和口味]
- **菜不是话题**：把注意力从菜单转到她身上（发色、一个故事）。[合理但未验证]
- **别给她夹菜、别忙前忙后**：一股服务员味。[合理但未验证]
- **转场**：大约 3 小时转 3–5 个地方，每个 ~40 分钟（散步、喝东西、抓娃娃、吃饭、酒吧）。她记住的是感觉，不是具体干了啥。[有研究支持：一起做新鲜的事能拉近距离]
- **第一次约会别看电影**：~90 分钟零互动；"不往前走的关系，会慢慢漂走"。[合理但未验证]
- **动起来，别干坐**：等位的时候走一走，避免像在开会。[合理但未验证]
- **多巴胺归因**：场景带来的兴奋感，会被算到你头上。[有研究支持：唤醒错误归因，效果中等偏小]
- **默认餐厅**：日料。光线暗、氛围舒服，不像西餐那么拘谨，也不像中餐那么油，两个人 ~¥150–200。[合理但未验证]
- **选项分浪漫和生活**："日料/西餐（浪漫）还是吃碗面（生活）？"选哪个都能拉近距离。[合理但未验证]
- **坐旁边，别坐对面**：诚实说法："坐这边来，我听不清。"原版是"去趟洗手间回来坐到她旁边"（大动作掩饰小动作）。[合理但未验证；她自在就行]
- **撤离**：一开始她很冷，短暂离开一下（去洗手间），气氛能重置，你也有时间想想怎么走。[合理但未验证]
- **控制情绪不讲理**：她烦了，用个玩笑或者小把戏转换一下气氛，别跟她辩。[合理但未验证。真是你惹的，就道歉]
- **立场前后一致**：做了决定（地点、点菜）别反复横跳。你已经往一个方向推了，就保持立场，换条路走（"你喝醉了我不去接，但我可以带你去吃好吃的"）。[合理但未验证]
- **当面具体地夸**：见第 4 节。[有研究支持]
- **及时止损**：地方不好、电影难看，就走。别因为沉没成本把她的心情从 60 分拖到 20 分。换个安排。[合理但未验证]
- **聊价值观**：积极地分享，轻轻地表达不同，别说教。[有研究支持]
- **讲故事**：童年的、走心的、好玩的故事能拉近距离。别讲恶心的。[有研究支持：自我暴露]
- **问她最喜欢和最讨厌的男生三个特质**：既能筛选，又是好话题。[合理但未验证]
- **打分玩笑（"1 到 10 分，你多喜欢我？"）**：[当游戏：合理但未验证。去掉"不能低于 5 分"]
- **离谱、好玩的话能看出她愿不愿意陪你玩（镜像原则）**：你不把她供在神坛上，她也会放下防备。[合理但未验证；看她自不自在]
- **好色坦白 / 真实**：承认你觉得她有吸引力，同时尊重她，好过虚伪（嘴上"我什么都给你"，结果饭钱都不出）。"心口不一就是猥琐。"[有研究支持：诚实]
- **让她投资**：小小的互相付出（"我做饭，你洗碗"）。[有研究支持：双方投入、宜家效应]
- **奖品 vs 赠品**：别她一提要求你就马上答应。人会更珍惜要花点力气才得到的东西。[合理但未验证。如果你拒绝的是你本来就想做的事，就属于操控性 → 诚实版本：想答应就答应；只是别什么都扔下去配合她]
- **要"更深一层的服务"**：她做个小动作时，俏皮地多要一点，让关系往前推。[合理但未验证；她一犹豫就停]
- **选择性拒绝**：不是什么都说好。[合理但未验证。"故意让人捉摸不透"那个版本属于操控性 → 诚实版本：按你真实的安排来拒绝]
- **买单**：你约的你买，或者 AA。"找你来买单，让她投入"和"女生会给受欢迎的男生买单"属于[操控性 → 诚实版本：按正常规矩来；有来有往自然会发生]
- **画饼**：去法国旅游、买包、"我的钱就是你的钱"。[操控性 → 不要用]
- **制造嫉妒（"等会我还要去见别的女生"）**：[操控性 → 不要用]
- **你迟到了**：认错，做个小补偿（"抱歉，我的锅。明天密室我请"），换话题，把计划往前推。别找借口。[有研究支持：简短、负责的道歉]
- **"你跟我见面是不是为了发朋友圈？"**：诚实回答，没问过她就绝不拍她。[有研究支持：隐私和信任]
- **以计划收尾**：下一个活动，或者"我今晚给你发消息"；她愿意的话抱一下。[合理但未验证]
- **集训演练**：模拟约会，针对体态、节奏、点菜、应对测试给反馈。[有研究支持：刻意练习]

## 10. 升级与同意

- **3+1 法则（小拉升测试）**：至少三次小升级（一句撩人的话、一个昵称、短暂碰一下胳膊），再来一次大的（牵手、接吻、邀请去家里）。小的都接住了就继续；她岔开，就是黄灯。[合理但未验证；是个靠谱的节奏规则]
- **越级行为**：升级 = 做一件比当前阶段更亲密一步的事。只在窗口出现后做。失败有三个原因：吸引不够、方法不对、时机不对。解决办法：回去继续建立吸引。[合理但未验证；去掉"三样都对就 100% 成功"]
- **好感测试 / 小测试**：在身体接触之前，先做低风险的试探（她喝你一口饮料、帮你拿下包、让你递个东西给她）。没成就笑笑换话题，别硬来。[合理但未验证]
- **距离测试**：手伸到她附近（递张纸巾），看她会不会往后躲。不躲 = 她自在。[合理但未验证；她只要往后躲就尊重]
- **让她来完成动作**："手给我看看，是不是变白了？"然后她自己把手放过来。给个理由，别直接抓。[合理但未验证；她很容易就能拒绝]
- **第一次接触要短**：≤2–3 秒就松开。先指尖再整只手。顺序是肩膀 → 轻轻碰一下 → 手。[合理但未验证]
- **氛围是第一要素**：氛围好，接触是受欢迎的；氛围不对，正常的请求也会被拒。[合理但未验证]
- **自然场景下的接触**：上下楼梯扶一下、过马路、共撑一把伞。[真心的话：合理但未验证。为了让她来不及说不而刻意设计借口（"大动作掩盖小动作"）就属于操控性 → 诚实版本：大方地把胳膊递过去，她可以不接]
- **给她擦嘴、摘睫毛、握手不放（"越漂亮握越久"）**：[操控性/越界 → 刚认识的人不要用]
- **该动不动也是失败**：她把手空出来、请你进门、明显在等你牵手，你还不动，可能被理解成没兴趣。但读错了就是"耍流氓"。[合理但未验证]
- **拿不准就问**："我能牵你的手吗？" / "我能亲你吗？"问一句会让她更自在，不会坏气氛。[有研究支持]
- **她一往回缩就停**：她哪怕稍微往回缩一下，就停下来，保持友好。"不"就是这条路到头了；黄灯就是放慢。[有研究支持]
- **承担责任式表白**：别把"你愿意做我女朋友吗？"说成求她给个判决，而是直接说你想要什么，再给她留出回答的空间（"我想让你做我女朋友。你慢慢想。"）。[合理但未验证。原版"你不用同意，我已经决定了"属于操控性 → 要把她的选择权说清楚]
- **尊重大于欲望**："承认你想要她没问题；女生介意的是被物化和虚伪，不是欲望本身。"[有研究支持]
- **去她家**：只有她清醒、明确地邀请才去。"那是你的主场"这类暗示，和"浪漫都是突然的"这种施压，属于[操控性 → 不要用]
- **拿酒当杠杆（"微醺了自然就发生了"、"你喝醉了我保护你"）**：[操控性 → 不要用。对方喝多了，不做任何升级]
- **"犹豫 = 同意" / "她没马上拒绝"**：[与研究相反 → 不要用]
- **她说了"你离太近了 / 别拍我 / 你没边界感"还继续**：[操控性 → 不要用。立刻退后]
- **拍摄**：没得到明确同意，绝不拍、绝不发别人。[有研究支持：隐私规范]

## 11. 约会后 / 两次约会之间 / 第二三次约会 / 确定关系

- **约会后发消息**：把你答应过的那条短消息发了（"到家了吗？今天很开心。"）。她问"要等多久"，或者第二天晚上她先找你，都是强信号。[合理但未验证]
- **两次约会之间别聊太多**：几次轻松的来回 + 下次的安排，好过天天聊。"不往前走的关系，会慢慢漂走。"[合理但未验证]
- **几天内就约下一次**：速度很重要；神秘感和好奇心会衰减。"追的时间越短，难度越低。"[合理但未验证；去掉"女生都是被刚认识的人追走的"，这和从朋友变恋人的数据相反]
- **用上你埋的钩子**：第一次约会提到的那个赌、那趟过山车、那部电影。[合理但未验证]
- **第二三次约会的推进**：每次多一点私密和亲近：吃饭 → 酒吧或散步 → 去她家或你家（只在双方明确愿意时）。典型案例路径：聊完第二天就约 → 第一次约会牵手 → 约 ~3 次 → 在一起。[合理但未验证]
- **~3 次约会确定关系**：从案例看，大概三次约会后正式在一起。[合理但未验证]
- **同一天转好几个场 = 一次顶好几次约会**：第一次见面时间长一点、转 3–5 个地方，熟得更快。[合理但未验证]
- **窗口打开了就别聊了**：她明显很想见你，就别再微信聊了，直接见。[合理但未验证]
- **"你到底喜不喜欢我？"**：原版"我喜不喜欢你不重要，你喜不喜欢我才重要"属于[操控性 → 诚实版本："喜欢啊。我做的比说的多。你呢？"]
- **"我不想一个人单方面付出"**：诚实版本：说出你的感受和你想要的。那句通牒"我感受不到，就用离开来表达"属于[操控性 → 诚实版本："我喜欢你，也想认真往下走。你要是没这个感觉，直接告诉我，我会认真对待。"]
- **确定关系**：直接说，别求（见第 10 节）。用行动和语言一起表达在乎。"只行动不表达"属于[与研究相反：说出来的爱意能预测关系满意度]
- **专属偏爱但不舔**："我不是对谁都这样，你是例外。"[是真的话：合理但未验证]
- **别靠承诺赢得信任**：没安全感的伴侣，需要的是前后一致加上边界，而不是发誓。"吸引和安全感，两个都要有。"[有研究支持：一致性建立信任]
- **真诚也有底线**：被反复怀疑时，"你一直试探我，我的真心也会受伤"是一个合理的边界。[合理但未验证]
- **"不替前任还债"**："伤你的人不是我；看我现在怎么做。"[合理但未验证]
- **距离（≤15 公里）**：优先找离得近的。跑很远去见面，容易投入过多，把约会变成一场高风险的大事。双方都应该付出一点成本。[合理但未验证；接近效应有研究支持]
- **做一个她骄傲的人，而不是"有用"的人**：她想要的是一个她乐意介绍给朋友的伴侣。[合理但未验证]

## 12. 冷掉、放鸽子、挽回与重新联系

- **先判断卡在哪个阶段**：第一条就冷 = 形象/匹配问题。先热后冷 = 聊天问题。聊了一个月还没约出来 = 卡在吸引阶段。[合理但未验证]
- **搞砸之后的两件事**：（1）让她注意到你变好了，（2）让她忘掉之前的坏印象。这两件事都不是靠聊天解决的；先改资料。[合理但未验证]
- **~7 天重置（"女生只有7天的记忆"）**：一次糟糕（或者很好）的聊天，大概一周就淡了。一次尴尬不是永久的；隔一段时间，可以重新开局。[作为经验法则：合理但未验证；这个数字没有证据]
- **沉默一周再发"hi"**：一次聊崩之后，安静 ~1 周（这期间正常更新真实的朋友圈），然后只发一个"hi"。别发"在干嘛"（需求感），别发"美女"（油腻）。[合理但未验证]
- **重新开口的话**："hi"；一个表情；"嗨 像你"这种轻松的呼应；"你上次说的那个[事]怎么样了？"；"看到 X，想到你了。"然后打游击：发一条就撤。[合理但未验证]
- **隔很久也没关系**：几周、几个月后，一个简单的"hi"也能重新打开。别为间隔道歉，也别解释。[合理但未验证]
- **隔了一阵她说"你好高冷"**：当成好感，不用写小作文。[合理但未验证]
- **追了一次还不回**：停。复盘、改进，真正重置之后再联系。[有研究支持]
- **她拒绝两次 / 约了三次都没成**：别再约了，保持友好，让她来主动。[有研究支持]
- **她回消息，但好几周都不肯见**：直接说一次你想见她，然后就放下。[有研究支持]
- **她在养鱼（收礼物，挡亲近）**：所有付出都停掉；只提供一起相处的时间。她还是躲，就走。[合理但未验证]
- **放鸽子 / 临时取消**：回一句（"没事。"），别当场马上再约。她提了新时间最好；没提就把球留在她那。别问"为什么"。[合理但未验证]
- **她约会迟到**：轻松地给个框架，语气软一点（"不愿意等我啊？开玩笑的，坐吧。"）。如果老这样，平静地划个边界。[合理但未验证]
- **她为了朋友取消**：提议换一天，别一次次迁就你的安排。[合理但未验证]
- **她的朋友 / 预选**：对她朋友友好，但别刻意去讨好。在社交上受欢迎（预选）有帮助；炫耀你认识多少女生没用。别撩她朋友。[合理但未验证；择偶模仿效应有研究支持，但效果不大]
- **她因为你没回消息生气**："怎么啦？"，别写道歉小作文。要是你确实不礼貌地晾了她，一句话道歉就够。[合理但未验证]
- **她删了你、拉黑你**：这就是答案。[有研究支持]
- **被删后换个号/编个"我们是在 App 上认识的"重新加回来（改头换面、信息差）**：[操控性 → 不要用；这就是骚扰]
- **找台阶的谎话（"我说的'我那'是指我家开的饭店"）**：[操控性 → 诚实版本："那天晚上我太冲了，对不起。你要是愿意，想约你喝杯咖啡重新来一次。"她已经删了你，就算了]
- **倒打一耙让她内疚（"现在知道你误会我了吧"）**：[操控性 → 不要用]
- **用她在俱乐部里说的心事编出"同病相怜"**：[操控性 → 诚实版本：只分享你自己的真实经历，别拿她的秘密当引子]
- **快速救活一段死掉的聊天（"打游击" + 窗口期）**：见第 6 节。[合理但未验证]

## 13. 关系维护与吵架

- **翻译需求**："你根本不在乎我" = "我想让你多在乎我一点。""你怎么不死在外面" = "早点回家。"回应的是需求。[有研究支持：听出背后的情感诉求]
- **看温度**：她吵得很凶，通常说明她还在投入；冷沉默才是要走的信号。[合理但未验证]
- **说出底下的东西**："我觉得你知道我喜欢你，但你没安全感，所以一直在确认。"再请她举个具体例子。被理解，比被说服更能让人平静。[有研究支持]
- **温和地转一下她的逻辑**："我们每天晚上都聊，为什么你还是感觉不到我喜欢你？"[合理但未验证；保持好奇，别变成对抗]
- **包容 + 底线（钻石）**：表面圆润，底下有棱角。"你需要什么直接说，合理的我都配合。但每次吵架都拿分手威胁，这越过我的底线了。"[有研究支持：边界 + 温暖]
- **给台阶 + 下指令**："好点了吗？我现在去接你。"[合理但未验证；前提是她同意]
- **她说"分手吧"别慌**：平静地尊重她的选择（"不管你怎么决定，我都尊重"）。[有研究支持：冷静、尊重的回应能降温]
- **错了就道歉**："永远别道歉 / 知错改错不认错"属于[与研究相反 → 真诚、具体的道歉能重建信任]
- **反咬一口（"你控制欲太强了"）**：[操控性 → 她的担心有道理时不要用]
- **律师招数（谁主张谁举证、行为性质定义、利益捆绑）**：[用来逃避责任就属于操控性 → 诚实版本：透明地解释，合适的话把聊天记录给她看，跟她一起商量和异性同事的边界]
- **冷战逼她来追**：[与研究相反；冷战（筑墙）是分手的预测指标。先暂停冷静一下，然后回来谈]
- **忽冷忽热（只行动不表达、抽离）**：[长期关系里与研究相反：只会制造焦虑。保持稳定的温暖]
- **礼物解决不了问题**：买个包，换来的是她对包的反应。去解决吸引或者信任的问题，别去记人情账（"该修 A，别去修 B"）。[合理但未验证]
- **事业和她怎么平衡**："告诉她你的事业比她重要"作为规则属于[与研究相反 → 诚实版本：守住工作时间，直接说清楚；同时让她知道她也很重要]
- **用不确定感维系关系（"她越不舒服就越喜欢你"）**：[操控性 → 不要用]
- **"使用权" / 在一起后还留后路**：[确定关系后就属于操控性 → 不要用]
- **长期的根基**：真实、一致、潜力、有担当。伴侣愿意陪你熬过难关，是因为人品，不是因为钱。[有研究支持]

## 14. 钱

- **80/20/0**：80% 花在自己身上（衣服、健身、技能、经历），20% 花在一起的体验上，0% 花在为了追她而送的礼物、包、转账或者在她身上的"投资"上。[合理但未验证；一起体验有研究支持]
- **为什么礼物是 0%**：礼物换来的是她对礼物的反应。没追到，你会觉得被骗了，可能会因此心生怨气（变得像跟踪狂）。功劳归给感觉产生时在场的人，不是买单的人。[方向上有研究支持：要拉近关系，体验 > 实物]
- **"钱是用来展示的，不是花在她身上的"**：[合理但未验证。诚实版本：让你的生活方式自己说话，别拿钱当诱饵]
- **花得少，成功率反而高**：还没在一起就砸很多钱，等于告诉她不用表态，你就一直卡在暧昧里。[合理但未验证]
- **质量大于数量**：¥300 点三个好菜，好过八个凑合的菜；一次很棒的体验好过五顿饭。[合理但未验证]
- **别哭穷**："我攒了三个月的钱才请你这顿"，等于暗示以后她要跟你一起扛。要给就给得像不算什么，不然就别给。[合理但未验证]
- **早期别炫**：超跑、奢侈品展示传递的是短期意图。[有研究支持]
- **便宜的约会也管用**：一整场逛街约会可以只花 ~¥40。案例里一次吃饭约会大概 ~¥280。[合理但未验证]
- **需求刻度杯**：每个人都有一个满分 100 的需求杯（颜值、地位/虚荣、性价值、情商/幽默、钱）；缺的那部分会用要求、礼物和服务来填——那是个无底洞。提高你自己的价值，她额外要的就少了。[合理但未验证；去掉具体分值]
- **一起消费 vs 投资她**：一起做的事你来付钱没问题；"投资"她（买衣服、转账）会抬高她的市场价值，她可能会换更好的。[合理但未验证。Rusbult 的投入模型对已经确定关系的伴侣给出的预测正好相反]
- **稀有才珍贵**：泛泛的好（早安短信、"多喝热水"、¥20 的外卖）不会让你脱颖而出。好要在吸引之后才有分量，而且要有门槛。[合理但未验证]
- **无缘无故的大好处，会被读出动机**："黄鼠狼给鸡拜年"。从小的开始，先请她帮个小忙，再请她。[有研究支持：对方没要的大人情会引起怀疑和压力]
- **装有钱装到生米煮成熟饭**：[操控性 → 不要用]
