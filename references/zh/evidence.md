# 研究证据与模型

用户问"这个说法对吗"、想知道建议为什么有效，或者他正在依赖某个该纠正的流行说法时，用这个文件。用大白话讲研究结论，用户没要的话不用堆引用。所有引用都是真实研究，但正式引用前请用户自己核对原文。

## 流行说法打分

| 说法 | 结论 | 原因 |
|---|---|---|
| 要有选择性，别对谁都好 | 支持 | 有选择的"难追"胜过对谁都好追或对谁都难追 (Walster 1973)；不加选择的好感更少得到回应 (Eastwick 2007)。 |
| 永远别表现出喜欢，要高冷 | **被否定** | "你喜欢我，我就更喜欢你"是最强的效应之一 (Montoya & Insko 2008)。不确定感只在已经表现出一些好感之后才有用。 |
| 让她捉摸不透，她就会一直想你 | 存疑 | 短期内会让她想得更多、更有吸引 (Whitchurch 2011)；但提高的是"想要"不是"喜欢"，而且只在她已经投入时才有效 (Dai 2014)。 |
| 先冷后热 | 支持 | 得失效应 (Aronson & Linder 1965)；不同重复实验里效应大小不一。 |
| 约会要多样、有新鲜感 | 支持 | 一起做新鲜、有点刺激的事能拉近距离 (Aron 2000)；心跳加速会被误认成心动 (Dutton & Aron 1974)。 |
| 越难得到越珍惜 | 存疑 | 有努力合理化效应和宜家效应，但没在恋爱中验证过；而且刻意让对方投入更多是一种操控。 |
| 给个理由，请求更容易被答应 | 支持 | Langer 1978。理由必须是真的。 |
| 先提小请求，再提大请求 | 支持 | 登门槛效应 (Freedman & Fraser 1966)。 |
| 具体的夸奖比笼统的好 | 存疑（间接支持） | 符合"感知到被回应"的研究 (Reis & Shaver 1988)。 |
| 多追问、互相分享自己的事 | 强支持 | 逐步加深的相互分享能制造亲密感 (Aron 1997)。 |
| 女生主要看钱和地位 | 存疑 | 问卷里的偏好很稳定 (Buss 1989)；但真实见面时的选择里影响很弱 (Eastwick & Finkel 2008; Kurzban & Weeden 2005)。 |
| 炫豪车吸引的是短期关系 | 支持 | 炫耀性消费被解读为想要短期关系 (Sundie 2011)。 |
| 老实人吃亏 | 基本不成立 | 善良更受青睐，尤其是长期关系 (Urbaniak & Kilmann 2003)；"坏"的特质只对短期关系有帮助 (Jonason 2009)。 |
| 幽默是核心吸引力 | 支持 | Bressler 2006。 |
| 让她有点怕你 | **被否定** | 威望不等于压制 (Henrich 2001; Cheng 2013)；恐惧会伤害关系。 |
| 永远别道歉、别解释 | **被否定** | 防御心态和冷战都是关系破裂的预测因素 (Gottman 1994)。 |
| 认识越短越好 | **被否定** | 多接触会增加好感，即曝光效应 (Zajonc 1968)。 |
| 犹豫就是同意，拒绝都是测试 | **被否定，而且危险** | 大多数拒绝都是真心的 (Muehlenhard & Hollabaugh 1988)。 |
| 聊崩了一周就忘了 | 未验证 | 只是听起来合理的经验法则。 |
| "十个男的抢一个女的" | 夸大 | 人口性别比接近 1:1；交友软件男多女少，但远没有 10:1。 |

规律：讲**过程**的建议站得住（节奏、幽默、好奇心、主导、多样的约会、不要需求感）。**对抗式的世界观**站不住（把拒绝当游戏、装高冷、靠压制）。

## 规则背后的简单模型

用来用一两句话解释*为什么*，不要变成数学课。

- **木桶效应。** 成功率 = 每一步通过率相乘，所以补最弱的一步收益最大。照片第一关就输了，再会聊也救不回来。拖太久也会降低成功率，因为兴趣会随时间衰减。
- **跳步骤。** 一个动作做在它该出现的阶段之前，会被重罚；一步一步来，几乎总比跳着走划算。
- **先模糊邀约。** 如果直接约被拒会让以后更难约，那就先来一句不费力的"改天一起去…"试探。如果被拒不影响以后，那就直接约。
- **回消息有最佳时间。** 晚回显示你有自己的生活，及时回应能建立亲密感。两者的权衡存在中间最优点，大概就是"正常速度"，可以用"跟她的节奏"来近似。
- **忽冷忽热。** 只有当"捉摸不透"带来的加分非常大时，掺点冷信号才划算；而在得失效应下，只有开头和结尾的信号有影响。所以要走一条从克制到温暖的弧线，而不是一直来回反复。
- **背熟的接招话术。** 如果大家都背同一套答案，答案就说明不了你自信；只有真正稳的状态经得起一次次测试。要真的变稳，而不是排练"很稳"。
- **80/20/0。** 如果早期送礼抬高她的其他选择，多过增加她的满意度，那么送礼的最优投入就是零。钱花在提升自己和一起经历的事情上。
- **硬价值和软价值。** 外貌、收入、地位决定你能接触到哪些人；幽默、温暖、自信、会聊、有主见决定在这些人里你能不能成，而且这些在见面时最起作用。装出来的地位是空话，一接触就穿帮。
- **为什么"不"必须算数。** 如果每个回答都被理解成"有戏"，这种解读就不含任何信息。概率上要把"不"当证据；尊重同意要把"不"当结论。

## 局限

大部分研究用的是西方样本，很多是大学生，在实验室或快速约会场景里做的，效应量都不大。具体的时间数字（隔 40 分钟回、一周冷却、"三次约会"）是经验法则，不是研究结论。用的时候要说清楚。
