## 1. 基本原则

- **短。** 一条两三行，一条只说一件事。把没用的软化词删掉："哈哈哈"刷屏、"就是想问问"、"不好意思打扰了"、句尾一串"~"。语气词也少用：发"在干嘛"，别发"在干嘛呀~"。
- **不连发。** 一句话拆成五条气泡轰炸，对方手机狂震，压力很大。想说的话合成一两条发。
- **有内容，别只回两个字。** 问"你哪里人"，别只回"东北"，回"东北的，所以滑雪还行，吃辣完全不行"。给对方能接的东西。
- **聊人，别聊流水账。** 聊对方是什么样的人（"你是早起型的人，还是说自己早起其实没起来的那种"），比问流程（"今天过得怎么样"）好得多。
- **一个问题，然后给反应。** 别一口气问三个问题。对方回答后，先给个看法、调侃一下或者讲个自己的小事，再问下一个。
- **回扣（callback）。** 提起对方之前说过的一句话，是"我有在认真听"最便宜的证明。
- **闲聊没问题。** 任何聊天里大概一半都是普通闲聊。每隔几句来一个"技巧"（调侃、钩子、小故事），不要每句都在使劲。
- **高点撤离。** 趁聊得正开心的时候收："先不聊了我去干活了，回头继续"。有时候让对方说最后一句。
- **微信聊天是用来约时间、制造期待的，不是用来谈完整场恋爱的。** 吸引力是见面时建立的，别把最好的料都耗在聊天框里。
- **语音 vs 文字。** 刚认识时发语音（尤其是长语音）压力比文字大：对方可能在上班、在地铁上不方便听，也会觉得被迫马上回。早期以文字为主；真要发语音，十秒以内、轻松一点。语音通话、视频等聊熟了、对方也愿意时再说。
- **拍一拍、表情包** 可以当轻松的互动和收尾，但不能代替真正的内容，更不能用来"催回复"。

## 2. 回复节奏

- 最好的节奏就是*正常*：不是秒回一切，也不是刻意晾着。适当的延迟说明你有自己的生活；而"被回应"的感觉（觉得对方在意自己）是拉近关系最强的因素之一。简单模型里最优点在中间，所以老实的规则就是"自然地回，大致跟对方节奏一样"。
- **跟对方的节奏走。** 对方一小时才回，你没必要 30 秒内回；对方回得快又热情，你快一点也完全没问题。
- 对方说了在忙（开车、上班、打游戏），就别这时候回，等对方有空再发，消息才会被认真看。
- 刻意拖很久（几小时甚至几天）只在最开始、对方发的是敷衍或"测试"类消息时说得过去。约会顺利之后，或者双方明显都有意思了，再玩这套只会被理解成你冷淡了。
- 永远别评论对方回得慢（"终于舍得回我了"）。也别为自己回得慢道歉，除非真的很失礼。

## 3. 从聊天里看兴趣

微信没有"已读"显示，所以别纠结"已读不回"，看的是回复的规律：回得多快、多长、谁先开口、会不会主动接话。

**窗口 / 绿灯：** 记得你几天甚至几周前随口提的小细节；回得比你还长；笑和语气词（"哈哈哈哈哈"、"真的假的？？"）；用表情包；主动跟你说自己今天怎么了（"累死了"）；反问你问题；问你名字或者你的安排；发照片给你；话题快断了主动续上；你没回时带点小抱怨（"人呢？"、拍了拍你）；自己提出见面。

**黄灯：** 你撩一下就被挡开（"你是在撩我吗哈哈"）；回得短但礼貌；只回答不反问；你约的时候说"再看吧"又不给别的时间。黄灯意味着慢下来，回到轻松聊天，过段时间再试，不是更用力。

**红灯：** 连续几天都是"嗯""哦""好"；一直"最近忙"又从不给替代时间；轻轻约了一下没回音，下一条也没回；被删好友 / 拉黑。红灯就停止投入。大多数拒绝都是真心的。

看几轮下来的趋势，别看单条。最有信息量的两个数字：双方回复长度的比例，以及谁先找谁。

另外可以看看**朋友圈**：对方给你点赞、评论，或者突然对你开放了朋友圈（之前是三天可见 / 屏蔽），都算小绿灯。但别过度解读，也别去翻对方三年前的朋友圈点赞。

## 4. 从聊天到约出来

- **先诊断。** 在探探 / Soul / 陌陌这类 App 上，前三条都没回 → 问题在头像 / 照片 / 开场白，不在聊天技巧。回了然后慢慢淡了 → 问题在聊天本身。聊了几周还没见面 → 你从来没约过。经验值：聊得不错的几天（3–7 天）或者二十来轮好的来回后就该约；聊了三轮以上还没约，就是卡住了。
- **约之前先探一下时间：** "这周末有什么安排？"——这样能避免直接撞上一个"不行"。
- **先模糊邀约：** "改天一起去吃你说的那家火锅"。没接住也没损失。
- **对方接得热，马上具体化：** "周四晚上七点？你家附近有家日料我一直想去" + 发个位置。一个具体的安排，比"你什么时候有空"好答应得多。
- **"顺便"的说法压力更小：** "我本来就要去吃那家泰餐，一起？"
- **主导，但别命令一个陌生人。** 所谓"下指令"，是自信、具体的邀约（"那就周四"），而不是请示（"那个……不知道你会不会愿意……"）。但永远给对方留拒绝的余地。
- **对方说不行但给了另一个时间**，那就是答应了，当场定下来。对方说不行也没给替代时间，最多过段时间再约一次；两次不成就把球交给对方："没事，你有空了跟我说"。
- **一次追逐原则**同样适用：约过一次没回音，最多补一条，然后停。

## 5. 约会后、两次约会之间

**当晚或者第二天早上：** 发一条简短、温暖的消息。回扣约会里的某个瞬间，比泛泛地说"谢谢今天"好。
> 今天很开心 现在想到你那个[具体观点/故事]还是想笑😂

约会不顺或者很平淡，发一句简短友好的收尾就行，不发也可以。

**第一次和第二次约会之间（第二次已经约好）：**
- 要聊，但轻一点。一周里轻轻碰一两次：回扣个梗、看到什么想到对方、几句斗嘴。不是从早到晚天天聊。
- 做那个在聊得正好时收尾的人。
- 跟对方的热度走：对方话多你可以多一点，对方安静你就保持轻松。对方没回的消息，别再追发第二条。
- 提前一两天确认安排，说清楚时间、地点、发位置。主导这些细节本身就是吸引力的一部分。
- 对方回得慢别过度解读（稳定）。也别把话题全聊完，见面时没话说。
- 这时候就别再刻意拖延回复了。不确定感只在最开始有用；双方都明显有意思之后，再拖就像在变冷。

**第一次约会后还没约下一次：** 一天之内发那条温暖的消息，并且趁感觉还在提出下一次："上次抓娃娃你赢了不服，周六再战？" 别等一周。

**之后的约会之间（第二、三次以后）：** 联系变多、变暖是自然的，这是健康的走向（一开始克制，双方都确认有意思后越来越暖）。如果双方都在天天聊，天天聊也没问题。关键是一直有下一次见面的安排，见面的势头比消息数量重要。

## 6. 冷场、淡掉和重新开聊

- **只追一次。** 一条消息没回，隔一两天轻轻补一条，然后就停。
- **补的那条要好回：** 新话题、一张照片、一句俏皮话。不要发"？"、"在吗？？"、"我是不是哪里说错了"。也别连着拍一拍对方。
- **聊死了不是永久的。** 一次尴尬的对话，大概一周左右对方基本就忘了（经验值，没验证过）。一周后用轻松、新的东西重新开聊，别提之前的冷场：
> 刚看到这个 第一反应就是你上次吐槽的那个[事]
- **重新联系一个已经冷掉的人之前**，先花一周把你的**朋友圈**打理成你真实生活的样子（你真的在做的事、朋友、爱好；删掉丧的、抱怨的、炫耀的）。朋友圈就是你的展示面，对方一定会去翻。
- **被删好友 / 拉黑，就是答案。** 永远不要换小号、换号重新加回来，也不要通过共同好友去要联系方式。
- **接受委婉的拒绝。** 连续两次"最近太忙了"又不给替代时间 → 体面地放手："没事，这周顺利呀"。门还开着，你的自尊也在。

## 7. 话术库

按用户自己的说话风格改。如果听起来不像用户本人，绝对不要原样发。

- **约会后：** "到家了吗？今天很开心" / "人十分，那家饺子六分，下次换一家再战"
- **周中轻碰：** "[回扣]更新：我试了，你是对的，我很不爽你是对的"
- **确认安排：** "周六还ok吧？七点[地点]，我先去占位" + 位置
- **模糊邀约：** "这家你肯定喜欢，改天去" / "行，这个问题我们得当面喝杯奶茶解决"
- **具体邀约：** "周四下班后？[区域]那边有个小酒馆不错"
- **探时间：** "这周末有安排吗？"
- **冷场后补一条：** 一张照片 + 一句话；一个新发现；一个轻松的回扣。不带任何埋怨。
- **收尾：** "我被叫走了，下集再续"
- **体面结束：** "没事没事，祝你一切顺利"

## 8. 帮用户分析聊天记录

用户发来聊天记录或截图时，按这个结构分析（聊天很短就压缩）：

1. **现在什么情况**——处在哪个阶段，趋势是变热 / 平 / 变冷，一句话说完。
2. **对方的信号**——引用对方原话里最能说明问题的 2–4 句，标绿灯 / 黄灯 / 红灯。要拿*对方自己的基线*来比：一个平时惜字如金的人回了三行，比一个话痨回三行信号强得多。谁先开口、双方消息长度的比例，是两个最有信息量的事实。
3. **你哪里做得不对（如果有的话）**——按代价从高到低：需求感的表现（小作文、连环问、连发、追发、凌晨两点秒回）、查户口式聊天、错过邀约的时机、被调侃时急着辩解。如果用户做得没问题，这部分就跳过，别硬挑毛病。
4. **发这条**——一条主推的回复，加一两个备选（比如俏皮版 / 直接版），每条用几个字说明意图和对方大概会怎么回。
5. **接下来 1–3 步**——带时间和分支（如果热 → ……，如果回得短 → ……，如果没回 → 只追一次，然后按 `recovery.md` 里的退出步骤走）。
